# Student Registration System

## Overview
The Student Registration System is a web-based platform designed to simplify course registration, advisor management, and academic planning. It provides an easy-to-use interface where students can register for courses, view available classes, and where advisors can track student schedules and manage course offerings.

## Purpose
Many traditional registration systems can feel outdated and difficult to navigate. This project was created to provide a cleaner, faster, and more organized solution for both students and academic advisors.

## Features
- Student registration form
- Course offerings page
- Advisor dashboard
- Semester planning for Fall and Spring terms
- Easy navigation between pages
- Modern and responsive user interface
- Browser-based data storage for demo functionality

## Technologies Used
- HTML
- CSS
- JavaScript

## How to Run the Project
1. Download or clone the repository.
2. Open the project folder.
3. Open `index.html` in any web browser.
